# tiwhub Mascot — Minimal Direction

ใช้ทรงเรียบ เส้นขอบ Learning Navy สี Oasis Blue และจุดเน้น Cyan เพื่อให้จำง่ายและยังอ่านออกเมื่อย่อเป็นรูปโปรไฟล์หรือไอคอน
