# TiwHub logo concepts

ทำไว้ 3 ชุดเพื่อเลือกทิศทางแบรนด์ **tiwhub** แต่ละชุดมีโลโก้แนวนอนแบบ SVG/PNG และสัญลักษณ์เดี่ยวแบบ SVG/PNG พื้นหลังโปร่งใส

## ชุดที่ 1 — Sage Link

โทน Sage สุขุมและเป็นมิตร ใช้ TH เชื่อมเป็นสัญลักษณ์เดียวกับจุดสีทอง สื่อถึงผู้ปกครอง นักเรียน และโรงเรียนที่เชื่อมถึงกัน

- สี: Sage `#718C76`, เขียวเข้ม `#304535`, ครีม `#FFFDF6`, ทอง `#D5B66B`
- [โลโก้ SVG](tiwhub-option-1-sage.svg) · [โลโก้ PNG](tiwhub-option-1-sage.png)
- [สัญลักษณ์ SVG](tiwhub-option-1-sage-mark.svg) · [สัญลักษณ์ PNG](tiwhub-option-1-sage-mark.png)

## ชุดที่ 2 — Oasis Pages

โทนน้ำเงินสดใส ให้ความรู้สึกด้านการศึกษาและความน่าเชื่อถือ ใช้รูปหนังสือเปิดกับจุด Cyan เป็นสัญลักษณ์การเรียนรู้ร่วมกัน

- สี: น้ำเงิน `#2563EB`, กรมท่า `#17335C`, Cyan `#06B6D4`, ขาว `#FFFFFF`
- [โลโก้ SVG](tiwhub-option-2-oasis.svg) · [โลโก้ PNG](tiwhub-option-2-oasis.png)
- [สัญลักษณ์ SVG](tiwhub-option-2-oasis-mark.svg) · [สัญลักษณ์ PNG](tiwhub-option-2-oasis-mark.png)

## ชุดที่ 3 — Bright Steps

โทนพลัมและคอรัลที่โดดเด่นขึ้น แต่ยังดูเป็นระบบการเรียน ใช้ตราหกเหลี่ยมและจุดเชื่อมสีสว่าง สื่อถึงการเติบโตเป็นขั้น ๆ

- สี: พลัม `#55365F`, คอรัล `#F07B62`, เหลือง `#F2C14E`, ครีม `#FFF8EF`
- [โลโก้ SVG](tiwhub-option-3-spark.svg) · [โลโก้ PNG](tiwhub-option-3-spark.png)
- [สัญลักษณ์ SVG](tiwhub-option-3-spark-mark.svg) · [สัญลักษณ์ PNG](tiwhub-option-3-spark-mark.png)

## วิธีเลือกและใช้งาน

เลือกชุดที่เข้ากับบุคลิกที่ต้องการก่อนนำไปแทนโลโก้ปัจจุบัน: **ชุด 1** สุขุมและต่อเนื่องกับ Rich Menu, **ชุด 2** เน้นภาพสถาบันการศึกษา, **ชุด 3** โดดเด่นและร่วมสมัย ใช้ SVG เมื่อระบบรองรับเพื่อความคมชัด หากใช้ PNG ให้รักษาสัดส่วนเดิมและไม่ยืดภาพ

ไฟล์ `tiwhub-logo.*` และ `tiwhub-mark.*` คือแบบเดิมที่ทำไว้ก่อนหน้า ยังไม่ถูกแทนที่ด้วยชุดใด เพื่อรอเลือกทิศทาง
