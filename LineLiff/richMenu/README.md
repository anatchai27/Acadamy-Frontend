# Rich Menu ผู้ปกครอง TiwHub

## ไฟล์ภาพ

- `rich-menu.png` — ภาพพร้อมอัปโหลดใน LINE Official Account, ขนาด 2500 × 1686 px
- `rich-menu.svg` — ไฟล์ต้นฉบับสำหรับแก้ไขข้อความ สี และไอคอน

ภาพใช้ Oasis Blue สลับพื้นขาวและฟ้าอ่อน พร้อมปุ่ม 6 ช่อง: หน้าหลัก, เช็กชื่อ, ค่าเรียน, แจ้งลา / ชดเชย, การบ้าน และคะแนน

## ตั้งค่าใน LINE Official Account

1. เข้า **LINE Official Account Manager → Rich menus** แล้วสร้างเมนูใหม่
2. อัปโหลด `rich-menu.png` และเลือกการแบ่งพื้นที่แบบกำหนดเอง 3 คอลัมน์ × 2 แถว
3. ตั้ง Action ของทั้ง 6 พื้นที่เป็น **Link / URI** และใส่ LIFF URL เดียวกัน:
   `https://liff.line.me/2010927966-x2dyK16K`
4. บันทึกและตั้งเมนูเป็นเมนูหลัก

URL นี้เปิดทางเข้า LIFF ที่แอปใช้อยู่ จากนั้นหน้าเข้าสู่ระบบจะพาไป Dashboard เมื่อยืนยันบัญชีแล้ว หากผู้ปกครองมีลูกหลายคน ให้เลือกเด็กจากตัวเลือกบน Dashboard ก่อนเปิดเมนูต่าง ๆ
